# АО «Монтре» — доходные дома

Сайт для инвесторов компании АО «Монтре». Компания выкупает исторические
и недооценённые здания, проводит реставрацию и ремонт и создаёт арендное
жильё (доходные дома).

## Структура (index.html)

Одностраничный сайт, единая тёплая гамма (кремовый / золото / графит), без курсива.
Логика блоков: обещание → о компании → модель → флагман → объекты → география →
рынок → инвесторам → вопросы → контакты.

## Что заменить перед публикацией

Места помечены комментариями в `index.html`:

- `[ФОТО]` — изображения объектов (сейчас временные стоки).
  Фон hero — `assets/hero.jpg` (реальный объект).
- `[КОНТАКТЫ]` — телефон и e-mail.

Данные по объектам взяты из справки для банка (реальные адреса, площади, статусы).
